# 模块 09 · 研究报告、学术写作与文献综合

> 一句话定位：本模块建立「结论可被追溯到证据」的写作规范——从研究问题、文献检索与来源评估，到 IMRaD 结构、引用规范、限制与外推边界，以及最常见的确认偏误防范。

## A. 学习导航

### 本模块解决什么问题

研究报告与商业分析报告的目标不同：它不为行动服务，而为「知识可以被信任地使用」服务。失败模式集中在四点：研究问题模糊导致收集无用材料；文献综述变成逐篇罗列；结论强度超出证据；限制与外推边界不写，导致后续引用者误用。本模块给出完整规范与操作步骤。

### 学习目标

- 能把一个宽泛兴趣转化为可回答的研究问题（含范围与目标）
- 能执行文献检索并按来源质量分级记录证据
- 能把「逐篇罗列」改写为主题综合（按观点/方法/证据组织）
- 能按 IMRaD 组织研究报告并说清各部分职责
- 能区分引文、直接转述、概括与原创分析
- 能正确使用引用规范并避免抄袭（含 AI 生成的引用风险）
- 能写出研究限制、不确定性与外推边界
- 能区分「作者的主张」与「研究本身的发现」

### 前置知识

- 模块 04（论证与批判性思维）：证据强度、结论强度
- 模块 08（分析报告）：与商业写作的差异
- 模块 16（事实核查）：来源分级与核查流程（可并行学习）

### 关键概念（中英对照）

| 中文术语 | 英文原名 | 一句话定义 |
| --- | --- | --- |
| 研究问题 | research question | 可被证据回答的明确问题 |
| 文献综述 | literature review | 按主题综合既有研究，非逐篇罗列 |
| IMRaD | Introduction, Methods, Results, and Discussion | 研究论文的标准结构 |

## B. 系统化知识讲解

### B.1 研究问题、范围与目标

- **研究问题**：可被证据回答的疑问。检验标准：能用「是/否」「多少」「哪种更好」「如何」之一回答。
- **范围界定**：对象、场景、时间、变量。范围不清是研究失败的首要原因。
- **研究目标**：你想达成什么——描述现状、检验关系、比较方案、解释机制。目标决定方法选择。

坏问题与改法：
- 「用户为什么流失？」（太大、不可直接回答）→「新用户在注册后 7 天内未完成首次下单的比例是多少？该比例在不同引导流程版本间是否存在差异？」
- 「AI 会不会取代写作？」（不可证伪）→「在给定任务类型与评价标准下，AI 生成文本与人类文本的评分差异有多大？」

### B.2 文献检索与来源评估

检索三条通路：
1. **学术检索**（Google Scholar、Crossref、PubMed 等）：按关键词 + 引用追踪（找到核心文献的引用与被引）
2. **机构与标准**：官方指南、标准组织、行业报告
3. **实践材料**：真实数据、案例、访谈——注意其代表性

来源评估五问：
1. 谁做的？作者资质与所属机构
2. 怎么做的？方法、样本、对照、局限
3. 为什么做？利益与资助来源（可能影响结论）
4. 谁引用？是否被广泛复核或已被推翻
5. 什么时候？时效性（技术、政策数据尤甚）

记录格式（证据卡片）：主张 / 来源（作者、年份、类型、链接）/ 方法与样本 / 关键结果 / 局限 / 我的判断（支持度与理由）。这张卡片同时服务于写作与核查（模块 16）。

### B.3 文献综述：主题综合而非罗列

**错误形式**（逐篇罗列）：
> 张三（2020）研究了 A。李四（2021）认为 B。王五（2022）发现 C。

**正确形式**（按主题组织）：
> 关于 X 的解释主要有三条路径。第一类……其代表研究是……共同结论是……但对……的样本给出相反结果，可能原因是……

组织维度可选：观点立场 / 方法类型 / 证据强度 / 时间发展 / 分歧点。
综述的落点必须是：**现有研究能回答什么、不能回答什么、本研究补哪一块**。

### B.4 IMRaD 结构

| 部分 | 职责 | 常见问题 |
| --- | --- | --- |
| Introduction | 研究问题、背景、缺口、目标、研究问题 | 背景过长掩盖缺口 |
| Methods | 设计、样本、变量、过程、分析方法、可复现信息 | 只写「我们做了调查」而不给样本细节 |
| Results | 结果呈现（不给解释） | 结果里混入解释与推断 |
| Discussion | 解释、与既有研究对照、限制、结论与建议 | 结论强度超出结果 |

铁律：**Results 呈现，Discussion 解释**。两者混写会让读者无法判断哪些是数据、哪些是你的解读。

### B.5 定性、定量与混合证据

| 类型 | 回答的问题 | 常见误用 |
| --- | --- | --- |
| 定量 | 多少、是否显著、关系强度 | 小样本过度推广；忽略情境 |
| 定性 | 如何、为什么、过程与意义 | 用个案推断普遍规律 |
| 混合 | 现象 + 机制 | 两部分未真正互相解释 |

混合设计的常见失败：定量部分证明「有相关」，定性部分说明「有体验」，但两者没有回答同一个问题——合并只增加了篇幅，没有增加理解。

### B.6 引文、转述、概括与原创分析

四者必须在文字上可区分：
- **直接引文**：逐字引用，加引号，注明出处与页码
- **转述**：用自己的语言复述他人观点，注明出处（不需要引号，但需注明「某研究认为……」）
- **概括**：综合多来源的共同结论
- **原创分析**：你自己的推理与判断——必须能被区分出来，不得混在转述中而不加标记

最常见的学术问题是**转述伪装成原创**（读者误以为是你自己的观点）或**原创伪装成转述**（把自己的判断藏在「研究表明」后，逃避责任）。

### B.7 引用规范与学术诚信

- 三大体系：APA、MLA、Chicago（见[资料库](../resources.html)）。选定后全篇一致，包括格式与页码处理。
- 基本要求：所有非原创内容均需标注来源；引用需对应文中实际出现的内容；不得引用未读过的文献（若只读了摘要，必须说明）。
- **AI 生成引用的红线**：AI 可以生成看似规范的书目，但虚构率不可忽略（模块 18）。每条引用必须通过检索确认存在性，并确认该来源确实包含你所引用的内容。
- 抄袭与合理使用的边界：改变表述不构成原创；诚实引用 + 综合分析是合法的学术写作。

### B.8 限制、不确定性与外推边界

每个研究都应包含：
1. **方法限制**：样本、时长、测量工具、成本约束带来的偏差
2. **结论不确定性**：哪些结论较稳健、哪些依赖假设、置信程度
3. **外推边界**：结论适用于哪些人群/场景/时间段，不适用于哪些

Nickerson（1998）指出，确认偏误不仅发生在研究者个体，也存在于文献整体——主流文献的共同前提本身可能被忽视。因此研究设计中应包含「主动检索反证」环节。

### B.9 避免选择性引用与确认偏误

操作规则：
1. 检索式同时包含支持与反驳方向（如「方法 X 有效」与「方法 X 局限」）
2. 证据卡片记录**所有**相关来源，包括不支持自己的
3. 写作前先写「可能的替代解释」一节
4. 结论强度与证据异质性匹配：证据一致 → 可较强；证据矛盾 → 结论应表达分歧
5. 让他人审阅「你的结论若为错，最可能错在哪」（模块 15）

## C. 逐步演示：产出一份可追溯来源的简短研究报告

### C.1 原始材料（示例情境，虚构）

兴趣：「远程办公对团队协作是否有影响？」可用材料：检索到的 3 篇研究（记录为 R1/R2/R3）、本公司问卷数据 n=86（待补充误差评估）、两名员工访谈。

### C.2 初始判断

问题过宽且不可回答（「有影响」既可正可负）。需要收窄为可回答、有数据支撑的形式。

### C.3 分析过程

1. 研究问题改写：「在本公司远程比例较高的产品团队中，感知协作效率与加班时长，与「同时间内有效沟通次数」之间的关系如何？」
2. 范围：本公司 X 个团队、6 个月、问卷自陈 + 可观测记录
3. 目标：描述现状 + 检验一个关系（不宣称因果）
4. 证据分级：R1–R3 为二手（他人研究结论）；问卷为自陈数据（一手但有偏差）；沟通记录为客观数据
5. 假设标注：H1 自陈协作效率与实际沟通次数可能存在偏差（H1 需检验）

### C.4 结构设计（IMRaD 简版）

引言（问题+缺口+目标）→ 方法（样本、变量、过程、局限）→ 结果（发现，不解释）→ 讨论（解释、对照 R1–R3、限制、结论）

### C.5 修改前后对照

| 修改前 | 修改后 | 解决的问题 |
| --- | --- | --- |
| 「远程办公有负面影响」 | 「在 X 团队样本中，自陈协作效率与加班时长呈同向变化，未观察到有效沟通次数的下降」 | 结论强度匹配证据；否定式结论需同等证据 |
| 「根据张三的研究…」 | 「R1（张三, 2020, 期刊论文, DOI…）报告远程团队沟通次数下降但产出持平；本研究未观察到前者」 | 引文规范化 + 明确差异 |
| 无方法说明 | 「样本：X 团队 86 人；期间：6 个月；数据：自陈问卷 + 沟通记录；已知偏差：自陈偏差、样本非随机」 | 可复现 + 限制前置 |
| 结果里混入解释 | 结果段只给数据；解释移入讨论段 | Results/Discussion 分离 |
| 「建议推广远程办公」 | 「样本不足以支持推广建议；建议先扩大样本并复核沟通记录口径」 | 外推边界 |

### C.6 最终版本（节选）

> **结论**：在本样本中，远程比例较高的团队，其自陈协作效率与加班时长呈同向变化，有效沟通次数未出现下降（n=86，6 个月）。该结果不支持「远程必然降低协作质量」的常见断言，但也不构成因果证据。
> **限制**：自陈数据存在已知偏差；样本来自三个团队，非随机抽样；沟通记录口径为工具内计数，可能遗漏线下沟通。
> **后续**：扩大样本并核对沟通记录口径后再评估因果解释。

### C.7 结果评估

可追溯性检验：随机抽查文中三个陈述——①「n=86」→ 指向方法段；②「R1 报告…」→ 指向参考文献；③「结论不支持…」→ 与结果段数据一致。三项均可回溯，无未标注的原创判断混入转述。

## D. 正例、反例与边界案例

| 类型 | 案例 | 说明 |
| --- | --- | --- |
| <span class="tag good">正确</span> | 「R1（作者, 年份, 类型, DOI）报告 X；本研究未观察到 X，可能因样本/时段差异」 | 引文规范 + 差异解释 + 不回避矛盾证据 |
| <span class="tag bad">错误</span> | 「众多研究表明远程办公提升效率」 | 无数量的「众多」+ 无具体来源；典型来源不明断言 |
| <span class="tag bad">错误</span> | 「据 ChatGPT 生成的参考文献 3（DOI: 10.1234/fake.2020）」 | 虚构引用，学术不端 |
| <span class="tag mix">易混淆</span> | 「作者主张」vs「研究本身发现」：「该团队认为方法 X 优于 Y」 | 应写「该研究报告 X 优于 Y」并注明测量口径；作者的主张可能超出其数据 |
| <span class="tag mix">边界</span> | 课堂报告/内部研究是否必须遵守 APA | 不强制，但必须可追溯且自洽；风格一致优先 |
| <span class="tag mix">边界</span> | 引用未读全文的文献（只读摘要） | 可引用摘要内容，但必须标注「依据摘要」 |

## E. 实战练习

### E.1 基础概念判断

1. 判断：文献综述是按时间顺序介绍前人工作。对还是错？
2. 判断：只要结论方向与多数研究一致，就可以省略少数派结果。对还是错？
3. 填空：研究报告中 Results 段应当只呈现 ______，解释放在 ______ 段。

<details markdown="1">
<summary>参考答案与解析</summary>

1. 错。时间顺序是罗列；综述应按主题、方法或立场综合，落点是「缺口在哪」。
2. 错。省略少数派结果是选择性引用（cherry-picking），会扭曲证据基础，也构成学术不端；正确做法是纳入并解释差异原因。
3. 结果；Discussion。
</details>

### E.2 方法应用

任务说明：把宽泛兴趣改写为可回答的研究问题。
输入材料：「我想研究大学生的时间管理。」「我想了解小红书内容策略。」「我们想知道新定价策略是否有效。」
完成要求：写出研究问题、范围（对象/变量/时间/场景）、研究目标（描述/检验关系/比较/解释机制）。
评价标准：问题可用是/否或数量回答；范围四项齐全；目标与方法匹配。

<details markdown="1">
<summary>参考解法</summary>

兴趣 1 → 问题：「该校 X 专业本科生每周用于课业与就业准备的时间分布如何，与 GPA 区间是否相关？」范围：X 专业、2025 秋季学期、自我报告小时数；目标：描述 + 检验相关（不可称因果）。
兴趣 2 → 问题：「头部同类账号中，含「实测对比」类内容与纯产品展示类内容的互动率差异有多大？」范围：平台、近 6 个月、头部 30 个账号、互动率定义明确；目标：比较。
兴趣 3 → 问题：「新定价在 X 类目上线两个季度后，毛利率与转化率分别变化多少？」目标：描述变化（若要因果，需对照或分期上线设计）。
</details>

### E.3 问题诊断

任务说明：找出下列研究报告的问题。
输入材料：「本文收集了 20 篇关于远程办公的文献，其中 15 篇认为远程提升效率，5 篇认为不利。本文认为远程提升效率。参考文献见文末。」
完成要求：指出至少五处问题并给出改法。
评价标准：识别计数式综述、无方法、结论覆盖异议、无引用规范、无限制。

<details markdown="1">
<summary>参考解法</summary>

1. 综述是计数而非综合 → 改：按方法/样本/结论条件分组综合，指出 5 篇反对者的共同前提差异。
2. 未写检索方法 → 改：交代检索平台、关键词、时间范围、纳入排除标准。
3. 结论忽略 5 篇异议 → 改：纳入异议并说明本文判断依据（样本、方法差异）。
4. 「本文认为」是作者主张，应与「文献显示」区分 → 改：分句表述。
5. 缺限制与外推边界 → 改：补方法限制（文献异质性）与适用条件。
6. 参考文献格式需统一（APA/MLA/Chicago 择一）。
</details>

### E.4 文本修改

任务说明：修正一段转述与原创混淆的文本。
输入材料：「研究表明远程办公能提高效率。由此可见公司应该推广远程办公。」（原文未给出处，且「研究表明」后内容实为作者自己的推断。）
完成要求：区分转述与原创；补出处占位与限定；给出两个版本（有来源版与无来源版）。
评价标准：四类表述可区分；结论强度匹配。

<details markdown="1">
<summary>参考解法</summary>

有来源版：「根据 [来源, 作者, 年份, 类型]，在 [样本/场景] 条件下，远程办公与效率指标呈正向关联（未建立因果）。本文据此建议在 [具体范围] 试点远程办公，并在 X 月后以 [指标] 评估。」
无来源版（无可靠来源时）：删除「研究表明」，改为假设表述：「假设远程办公能提高效率（待验证）。建议先在 X 团队做 8 周试点，以 [指标] 判断是否成立。」——来源不明时，缩小结论范围或明确说明证据不足（模块 16）。
</details>

### E.5 综合产出

任务说明：写一份 1200–1800 字的简短研究报告。
输入材料：任一可研究的问题 + 至少 3 个可追溯来源（至少 1 个一手来源）。
完成要求：IMRaD 四段齐全；含证据卡片附录（≥3 条）；含限制与外推边界；引用格式统一。
评价标准：任一结论可追溯到具体来源；无未标注的原创判断混入转述；限制具体可检验。

<details markdown="1">
<summary>评分维度</summary>

1. 研究问题可回答、范围明确——20
2. 综述为综合而非罗列——20
3. 引用规范一致且均可验证——20
4. 结果与讨论分离——15
5. 限制与外推边界具体——15
6. 结论强度与证据匹配——10
</details>

## F. 复盘与知识巩固

### 核心知识总结

- 研究问题必须可被证据回答；范围（对象/变量/时间/场景）四项界定
- 证据卡片：主张/来源/方法样本/关键结果/局限/我的判断
- 综述按主题综合，落点是缺口；计数式综述等于未综合
- Results 呈现，Discussion 解释——不可混写
- 四类表述（引文/转述/概括/原创）必须可区分
- 引用规范全篇统一；未读全文须注明「依据摘要」；AI 引用必须验证存在性
- 限制 + 不确定性 + 外推边界缺一不可
- 主动检索反证是对确认偏误的制度性防范

### 常见错误检查表

- [ ] 研究问题是否可用是/否或数量回答
- [ ] 范围四项是否明确
- [ ] 综述是否按主题而非顺序组织
- [ ] 是否交代检索方法与纳入标准
- [ ] 结果段是否混入解释
- [ ] 每条引用是否可检索验证
- [ ] 是否存在「研究表明」而无具体来源
- [ ] 是否写出限制、不确定性与外推边界

### 自我评估题

1. 为什么「20 篇文献中 15 篇支持 X」不能作为结论依据？
2. 转述与原创分析混淆会造成什么后果？
3. 主动检索反证如何制度化？

<details markdown="1">
<summary>参考答案要点</summary>

1. 因为文献质量异质（方法、样本、发表偏差），简单计数把异质证据当作同等权重；且发表偏差使阳性结果更易发表，计数会系统性高估支持度。
2. 后果：读者误把作者判断当作文献结论（原创伪装成转述，逃避责任），或误把自己的观点当作他人结论而无法回溯（转述伪装成原创，损害可追溯性）。
3. 制度化做法：检索式对称（同时搜支持与反对）；证据卡片强制记录不支持自己的来源；写作前先写「替代解释」节；结论前做「若我的结论为错，最可能错在哪」测试；邀请他人做反方审阅。
</details>
