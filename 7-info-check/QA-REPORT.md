1. **RAG 法律工具幻觉率（>17%）为转述来源**：原始论文未直接获取。已在网站案例 6 与 SOURCES.md 双重标注，并设计为毕业项目 C 的练习任务。

## 5. 已知的兼容性问题

| 项目 | 说明 |
|------|------|
| 剪贴板 API | 需 HTTPS 或 localhost 环境；`file://` 协议下部分浏览器限制 `navigator.clipboard`，已实现 `execCommand` 降级路径 |
| localStorage | `file://` 下 Chrome/Firefox 可用；个别浏览器/隐私模式下可能被禁用，页面已说明"数据仅存本地、无云端同步"的局限 |
| 旧版浏览器 | 需要支持 ES5+ 与 CSS 变量的浏览器（2018 年以后的主流浏览器）；使用了 `(?<=...)` 后行断言（AI 拆解分句），需较新浏览器（Chrome 62+/Edge 79+/Firefox 78+），旧浏览器中该功能不可用但不影响其他功能 |
| 外部链接 | 需联网打开；已核验可达（反爬站点除外） |
| 移动端 | 侧栏折叠为抽屉菜单，工具表格横向滚动，已在 CSS 层处理 |
