# 跨境电商全体系自学指南

一套可离线打开、长期查阅的交互式 HTML 自学课程。以独立站与 DTC 品牌电商为主线，兼顾 Amazon 等第三方平台、B2B 与 B2C 差异，覆盖从市场机会到全球合规的完整业务链。

- 版本：v1.0
- 内容更新：2026-10-16
- 结构：25 个模块 · 7 个学习阶段 · P0/P1/P2 优先级 · 10 个跨模块综合案例 · 十步综合实战项目

## 启动方式

直接双击 `index.html` 即可在浏览器中打开，无需服务器、无需构建、无外部依赖（核心内容完全离线可读）。

- 推荐桌面浏览器：Chrome / Edge / Firefox / Safari 最新版
- 移动端：左侧目录自动收为抽屉，单列阅读

## 内容维护

1. **改课程结构/优先级/术语**：只改 `assets/js/data.js`（COURSE / GLOSSARY），侧栏、首页卡片、搜索索引、术语表会自动同步。
2. **改样式**：只改 `assets/css/style.css`，颜色/字号/间距均为 CSS 变量。
3. **改课程正文**：编辑对应 `modules/stage-*.html`；每个模块为 `<section class="module" id="mXX">`，锚点与 data.js 中的 `anchor` 对应，新增模块需同步 data.js。
4. **改引用**：编辑 `sources.html` 或各模块“参考资料”小节，保持“标题/机构/链接/适用模块/核验状态”五要素。
