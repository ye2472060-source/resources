# Writing & Structured Expression · 写作与结构化表达自学系统

一套系统、全面、可实践的中文自学知识体系，覆盖从清晰思考到专业表达的完整能力链。本站为纯静态多页面网站，无需构建服务器、无外部依赖，可离线使用。

## 目录结构

```
writing-system/
├── index.html                  # 首页：知识门户、能力地图、学习路径、模块卡片、进度总览
├── modules/                    # 20 个课程模块页面
│   ├── module-00.html          # 总框架
│   ├── module-01.html … module-19.html
├── assets/
│   ├── styles.css              # 全站样式（暖白/墨色/森林绿/赭金配色）
│   ├── app.js                  # 交互脚本（搜索、目录、进度、复制、响应式）
│   ├── search-index.json       # 由构建脚本生成的全站搜索索引（HTTP 场景备用）
│   └── search-index.js         # 同一索引的 JS 版本，首次搜索时按需加载（兼容 file://）
├── content/                    # 课程 Markdown 源文件（模块与页面同源）
│   ├── module-00.md … module-19.md
│   ├── integration.md          # 整合设计：概念对照/方法选择/工作流/错误诊断树/跨场景案例
│   ├── glossary.md             # 术语词典
│   ├── templates.md            # 模板库
│   ├── resources.md            # 资料库（来源核验记录）
│   └── projects.md             # 综合项目
├── tools/
│   └── build.py                # 静态站点生成器（Markdown → HTML + 搜索索引）
└── README.md
```

## 使用方式

直接用现代浏览器打开 `index.html` 即可（支持 file:// 协议）。所有交互功能均为本地实现：

- **全站导航**：顶部导航栏 + 每页底部前后模块导航。
- **侧边目录**：课程页右侧/左侧目录，点击锚点跳转，滚动时自动高亮当前章节；窄屏下通过「目录」按钮抽出抽屉。
- **站内搜索**：顶部搜索框，检索范围包括模块标题、章节标题与正文内容。索引在首次搜索时按需加载 `assets/search-index.js`（约 560 KB，不影响首屏加载），并以 `search-index.json` 作为 HTTP 场景的备用来源，因此直接双击 `index.html`（file:// 协议）也能正常搜索。
- **折叠答案**：练习参考答案默认折叠，点击展开。
- **学习进度**：模块页侧栏「标记为已完成」，首页显示完成统计；进度仅存于浏览器 localStorage，属本地个人数据，无账号同步。
- **模板复制**：模板库每个模板右上角「复制」按钮。
- **阅读进度**：顶部细线显示当前页面阅读位置。

## 重新生成站点

修改 `content/*.md` 后运行：

```bash
python tools/build.py
```

会重新生成 `modules/*.html`、五个整合页面与 `assets/search-index.json`。首页 `index.html` 为手工维护的知识门户页（模块卡片清单），新增模块时需同步更新。

## 内容与来源

- 课程主体为简体中文，重要概念保留英文原名。
- 全部外部资料来源经过核验，登记于「资料库」页（resources.html），按证据分级组织；未采用任何无法确认出处的内容。
- 教学示例中的人物、公司、数据均标注为虚构示例情境。

## 已知限制

- 搜索索引在**首次搜索时**加载，首次搜索会有约 0.2–0.5 秒等待（本地读取）。
- 进度存储为 localStorage，不同浏览器/设备间不同步；清除站点数据会重置。
- 书籍类参考资料仅引用公开出版信息，课程内容基于其公认核心观点的转述，未声称已阅读无法合法访问的全文。
- 课程内容由多个并行编写单元分别产出并经统一校验（链接、标题层级、来源白名单、占位符扫描）；尚未进行真人读者测试，交互功能仅通过静态检查与语法校验验证，未做跨浏览器实测。
