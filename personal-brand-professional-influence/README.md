# 个人品牌与专业影响力 · 交互式自学课程

一套系统、深入、可持续更新的「个人品牌与专业影响力」自学知识体系，制作成交互式 HTML 学习网站。

> 课程目标：让你能独立理解、规划、建设并经营自己的专业品牌，并具备将专业影响力转化为职业机会、客户资源或商业收入的能力。

---

## 一、快速开始

1. 用现代浏览器（Chrome / Edge / Firefox / Safari）直接打开 `index.html`。
2. 无需安装任何环境、无外部依赖、无后端服务；可离线使用，也可放入任意静态托管。
3. 建议从左侧导航「模块 0」或首页「从模块 0 开始学习」进入，按四阶段路径推进。

**文件清单**

| 文件 | 用途 |
|---|---|
| `index.html` | 完整可交互学习网站（唯一必需文件，约 282 KB） |
| `README.md` | 本说明：使用方法、功能、课程结构与已知限制 |
| `sources.md` | 51 个核心参考资料的完整目录（标题/作者/链接/类型/日期/核查日期） |
| `research_notes.md` | 研究过程中的关键判断、争议问题、证据局限与资料缺口 |
| `build/` | 构建目录：模板、数据文件、构建与测试脚本（重新构建课程用，普通用户可忽略） |

## 二、课程结构

### 2.1 四阶段学习路径

| 阶段 | 名称 | 模块 | 建议投入 | 验收条件 |
|---|---|---|---|---|
| 一 | 建立认知 | M0 | 8–10 小时 | 写出个人品牌工作定义；画出核心逻辑链；模块自测 ≥80% |
| 二 | 构建基础 | M1 M2 | 16–20 小时 | 产出定位画布与能力档案；定位经 5 次访谈或内容测试验证 |
| 三 | 运营与增长 | M3 M4 M6 | 24–30 小时 | 发布 ≥4 篇真实内容并记录数据；完成一次对照实验 |
| 四 | 影响力与商业化 | M5 M7 M8 M9 | 30–36 小时 | 获得 1 个真实第三方认可；完成一次商业验证；产出 12 周复盘 |

时长为规划参考，非客观定律，请按自身基础调整。

### 2.2 十个模块

| 模块 | 标题 | 核心问题 |
|---|---|---|
| M0 | 概念、历史与底层逻辑 | 个人品牌究竟是什么、为什么有效、不能解决什么 |
| M1 | 个人盘点与专业定位 | 我能长期提供什么价值、让谁因为什么认识我 |
| M2 | 专业能力、知识资产与可信度 | 如何建立真实、可证明、可积累的专业基础 |
| M3 | 内容策略与专业知识表达 | 如何持续生产解决问题并积累资产的内容 |
| M4 | 平台选择、分发机制与运营 | 各平台如何帮助专业人士被发现，如何选择与运营；含国际平台与国内平台（公众号/视频号、小红书、B站、抖音、知乎）的机制与合规 |
| M5 | 专业影响力的形成与积累 | 从被看见到被信任、被推荐、被认为值得合作 |
| M6 | 数据分析与增长实验 | 用证据判断真实进展，区分运气与策略 |
| M7 | 商业模式与变现 | 影响力如何产生经济价值，如何小成本验证 |
| M8 | 战略管理与可持续经营 | 如何持续数年而非短期冲刺 |
| M9 | 综合案例、实战项目与验证 | 整合全部知识完成 12 周建设项目 |

每个模块统一采用 14 部分教学结构：学习目标 / 关键问题 / 概念体系 / 底层原理 / 研究证据 / 方法工具 / 操作流程 / 案例分析 / 实操练习 / 成果产出 / 自我测试 / 常见误区 / 进阶阅读 / 模块关联。全课程共 **65 个章节、41 个实操任务、54 道自测题、8 幅 SVG 知识图谱**。

## 三、网站功能

| 功能 | 说明 |
|---|---|
| 课程导航 | 左侧模块/章节树，可展开收起，当前章节高亮；顶部面包屑 |
| 学习进度 | 每节可「标记已学完」；进度保存在浏览器 localStorage，**不上传任何数据**；无存储权限时自动降级为会话内有效并提示 |
| 搜索 | 顶部搜索框，覆盖模块标题、正文、术语、来源；支持键盘上下选择与回车跳转 |
| 筛选 | 资料库按类型筛选（学术研究 17 / 官方文档 14 / 机构报告 6 / 专业著作 5 / 实践案例 2） |
| 折叠区块 | 延伸阅读、详细证据与补充说明可展开收起 |
| 学习任务 | 练习带复选框，完成状态本地保存 |
| 知识测试 | 每模块 5–9 题，提交后显示正确答案与解释（含来源编号） |
| 来源跳转 | 正文蓝色上标编号（如 [S01]）点击跳转资料库对应条目并高亮 |
| 阅读体验 | 返回顶部、章节锚点、上一节/下一节、顶部阅读进度条 |
| 响应式 | 桌面三栏；≤1280px 右侧辅助区折叠为页内目录；≤1024px 左侧导航变抽屉 |
| 无障碍 | 语义化标签、可见焦点状态、SVG 文本说明、`prefers-reduced-motion` 支持 |

## 四、内容与证据标准

- **证据分级标识**：蓝色「研究证据」（学术研究支持）、青色「官方规则」（平台/法规当前官方文档）、灰色「实践方法」（从业方法论，未经普遍验证）、橙色「风险提示」（限制、争议或合规风险）。
- **来源可追溯**：重要观点在正文中以上标编号引用 `sources.md` 中的条目；平台规则均标注核查日期（国际来源 2026-10-15，国内平台来源 2026-10-18）。
- **案例诚实标注**：案例一、三为明确标注的假设性案例；案例二基于公开记录并标注了数字的核验局限。
- **已知限制**：
  1. 部分学术文献仅核查了摘要与公开信息（详见 research_notes.md），未声称阅读全文；
  2. 平台规则随时间变化，本课程规则快照日期为：国际来源 2026-10-15、国内平台来源 2026-10-18；
  3. 第三方引述的平台统计（如 Substack 推荐贡献比例）未经官方页面直接核验，已标注局限；
  4. 网站正文由 JavaScript 渲染，禁用 JS 时无法阅读正文（页面内有 noscript 说明），完整来源与研究说明可查看随附 Markdown 文件。

## 五、重新构建（可选）

课程内容与模板分离存放于 `build/` 目录，修改内容后重新生成：

```bash
python build/build.py          # 整合模板与数据 → index.html
node build/validate.js         # 数据完整性校验（章节/来源/任务/测验/HTML 配对）
node build/smoke.js            # 全部 92 个路由的渲染冒烟测试
node build/e2e.js              # Playwright 真实浏览器功能测试（需 playwright）
node build/gen_sources.js      # 从数据重新生成 sources.md
```

文件结构：`build/template.html`（框架+样式+引擎）、`build/data_m0.js … data_m9.js`（课程内容）、`build/data_meta.js`（阶段与项目）、`build/data_sources.js`（来源清单）。

## 六、维护建议

- **每季度**：核查资料库中平台规则的当前状态（规则变化快的平台优先）。
- **每半年**：检索一次个人品牌与创作者经济领域的新研究，补充「研究证据」。
- **内容更新**：新增章节只需在对应 `data_m*.js` 中追加 section 对象并重新构建，导航、进度、搜索自动生效。
