# Sales & Negotiation Mastery · 销售与谈判能力系统学习

单文件交互式学习网站。核心交付物：**`sales-negotiation-mastery.html`**（位于本文件夹根目录）。

## 使用方法

1. 直接用现代浏览器（Chrome / Edge / Firefox / Safari）打开 `sales-negotiation-mastery.html`。
2. 无需安装任何环境、无需联网、无外部依赖（字体使用系统字体栈）。
3. 学习进度、测验得分、笔记、自评结果保存在浏览器 localStorage——仅存在当前浏览器，不会跨设备同步；清理浏览器数据会丢失。
4. 建议学习顺序：首页 → 知识地图（建立整体框架）→ 五阶段学习路径 → 按阶段完成模块 01—17 → 工具库按场景取用 → 综合案例与模拟训练 → 测评页自评。

## 证据分层约定

- 绿色框「证据：已有研究支持」= 同行评审研究或可核实现场实验。
- 蓝色框「理论依据」= 有理论模型、效果依条件而定。
- 灰色框「实践建议」= 专家经验或企业方法论（SPIN、MEDDPICC、挑战者销售等），未经严格因果验证。
- 黄色框「模拟案例」= 虚构教学案例。
- 紫色框「争议与不确定性」= 证据不一致或存在争议的结论。

## 目录说明（构建文件，非交付必需）

```
build/
  SPEC-fragments.md        内容片段编写规范（HTML class 契约）
  VERIFIED_SOURCES.md      来源库第一批（R01—R22，主控核验）
  VERIFIED_SOURCES_R2.md   来源库第二批（R23—R58，含更正记录）
  frag/                    17 个 HTML 片段 + 图示 + 脚本
  assemble.py              解析来源库→生成参考页→拼接单文件
  verify.py                结构 / 导航 / 引用 / 图示 / JS 语法验收
  smoke-test.js            jsdom 运行时冒烟测试
```

重新构建：`python build/assemble.py && python build/verify.py`，运行时测试：`node build/smoke-test.js`（需 jsdom）。

## 已知限制

- 进度与笔记仅存于当前浏览器，无云端同步。
- 工具填写模式的内容保存在 localStorage，清空浏览器数据后需重新填写。
- 测验与自评仅提供学习反馈，不等同于真实销售业绩或专业资格认证。
- 部分经典方法（SPIN、挑战者销售）的证据基础为商业实践研究，页面已标注；引用数字以原始出版口径为准。
