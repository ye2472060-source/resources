# 数据分析与商业决策 · 自学体系与交互式学习平台

一套从**零基础到能独立完成真实商业分析项目**的完整自学知识体系，并封装为一个**可直接打开使用的单文件交互式 HTML 学习平台**。

本文件夹即该作品的完整交付物。所有教程正文、练习、项目、图示均内置于 HTML 文件中，核心内容**离线可用**，无需安装任何环境或登录服务。

## 一、如何打开

- **最简方式**：双击 `data-analysis-business-decision-learning.html`，用任意主流桌面浏览器（Chrome / Edge / Firefox / Safari）打开即可。
- 若在本工作区中查看：在对话里点击本文件后系统会自动预览；如预览失效，请直接用浏览器打开上述路径。
- **不依赖联网**：打开与浏览课程内容不需要网络；仅当点击页面内「参考资料」的外部链接、或刷新 GA4/官方文档时才需联网。

## 三、平台能做什么

- **六大核心模块 + 跨模块能力**，共 **260 个知识卡片**（A 28 · B 34 · C 44 · D 53 · E 41 · F 43 · X 17）。每张卡片按 15 要素组织：解释 / 为什么学 / 前置 / 原理 / 操作 / 示例 / 解读 / 常见错误 / 边界 / 关联 / 练习 / 完成标准 / 资源 / 掌握程度。
- **分层练习**：每个模块含「入门 / 综合 / 业务」三档练习，提示 → 步骤 → 答案**分层展示**，先练后看。
- **9 个原生 SVG 教学图示**：数据工作流、SQL 执行顺序、表关联重复计数、GA4 事件模型、转化漏斗、分布偏态、相关 vs 因果、KPI 树、决策闭环。
- **知识图谱**：14 个节点 / 21 条依赖边，节点可点击跳转。
- **学习路线**：默认 9 阶段主线（含进入条件、参考时间、阶段性产出、完成标准、常见卡点、下一阶段进入条件）+ 4 条目标变体（工作应用 / 网站营销 / 商业分析 / 进阶分析）。
- **5 个实战项目**：从问题定义到行动建议的完整链路，附数据字典、验收标准、常见失败方式、参考解法、作品集形式。
- **7 类工具速查库**（125 条）：Excel 函数、SQL 语法、GA4 指标、统计方法、图表选择、KPI 模板、分析框架。
- **33 条参考资料**：GA4 帮助中心、Microsoft 支持、PostgreSQL 文档、SQLBolt、OpenStax、可汗学院、Skillshop 等，已逐一核实。

## 六、学习建议

1. **先问题，后工具**：模块 A 没过，不要急着学 Excel/SQL/GA4，否则工具越好错得越远。
2. **边练边标记**：每学一个知识点就在页面里标「已掌握」，用真实进度驱动学习。
3. **完成项目才算学会**：5 个项目是检验能力的最终标准，优先把项目 1（Excel 经营分析）做出来。
4. **把结论分层**：业务建议必须含责任人、完成时间、验证指标，否则只是「做了分析」而非「支持决策」。
