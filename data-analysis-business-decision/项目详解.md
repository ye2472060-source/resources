# 综合实战项目详解（5 个）

每个项目都要求走完「业务问题 → 指标口径 → 数据质量 → 提取/清洗 → 方法 → 分析 → 可视化 → 结论与不确定性 → 方案比较 → 行动建议 → 效果验证」的完整链路。所有样例数据均为教学模拟数据，已在页面内明确标注，非真实企业数据。

## 项目 1：销售与经营数据分析

- **编号**：P1　**难度**：L1–L2　**涉及工具**：Excel　**关联模块**：A、B、F
- **项目背景**：你接手一家电商的月度经营分析。业务方想知道：这个月卖得怎么样、问题在哪、下个月该关注什么。
- **业务目标**：用 Excel 清洗销售数据，分析收入、订单、产品表现、客户分布与时间趋势，产出经营报告。
- **最终产出**：月度经营报告（指标卡+渠道×月矩阵+TOP10+异常清单+结论与建议）
- **验收标准**：底表可复用且清洗留痕,所有数字可追溯（函数/透视交叉验证）,报告结论先行，建议含责任人与验证指标
- **常见失败方式**：直接对未清洗数据汇总,合并单元格表头导致透视错误,只报总量不报结构与环比,建议无验证方式
- **作品集形式**：报告+底表+一页“方法论说明”（口径与清洗记录），可作为求职/接单作品。

## 项目 2：SQL 商业分析

- **编号**：P2　**难度**：L2　**涉及工具**：SQL（SQLite/PostgreSQL/BigQuery 任一）　**关联模块**：A、C、F
- **项目背景**：数据库中有客户、订单、订单商品、商品四张表。业务方提出一组问题，需要你写出正确且可验证的查询。
- **业务目标**：用多表关联与聚合回答业务问题，并对每条查询做正确性检查。
- **最终产出**：一套带注释的 SQL 脚本+结果解读文档（每条查询附验证记录）
- **验收标准**：每条查询有验证记录（行数/合计/边界/双路）,JOIN 无重复计数,CTE 命名与注释规范
- **常见失败方式**：JOIN 后 SUM 翻倍,把事件数当用户数,查询无注释无法维护,只跑不看结果合理性
- **作品集形式**：SQL 脚本+结果解读，可直接作为技术面试作品。

## 项目 3：网站与流量分析

- **编号**：P3　**难度**：L2　**涉及工具**：GA4（或 GA4 风格导出数据）+Excel　**关联模块**：A、D、F
- **项目背景**：一个 B2B 服务站的经理说：“流量没少，询盘却少了。”你需要用 GA4 找出原因区域，并设计验证。
- **业务目标**：用 GA4 分析渠道、落地页、行为与转化，建立排查流程并提出优化假设。
- **最终产出**：诊断报告（现象-假设-验证计划）+渠道评估矩阵
- **验收标准**：结论按事实/解释/假设/建议分层,排查顺序体现“先数据后业务”,每个假设有验证方式
- **常见失败方式**：把相关当因果直接下结论,忽略追踪变更与阈值,建议无验证,用总体漏斗掩盖渠道差异
- **作品集形式**：诊断报告+渠道矩阵+假设验证计划。

## 项目 4：营销漏斗与转化分析

- **编号**：P4　**难度**：L2–L3　**涉及工具**：SQL/Excel + 统计　**关联模块**：C、E、F
- **项目背景**：一个电商站点希望你回答：用户在哪些环节流失？哪些流失值得修？某个改版是否真的有效？
- **业务目标**：结合分群、漏斗与统计方法，区分现象、原因假设与已验证结论。
- **最终产出**：漏斗分析报告（含统计解读与结论分级）
- **验收标准**：漏斗口径明确、分群对比控制变量,变化结论含区间与样本量,优化优先级有依据
- **常见失败方式**：不去重导致漏斗虚高,小样本变化当显著,把漏斗现象当原因,优先级拍脑袋
- **作品集形式**：分析报告+SQL+结论分级表。

## 项目 5：综合商业决策项目

- **编号**：P5　**难度**：L3　**涉及工具**：全工具链　**关联模块**：A、B、C、D、E、F、X
- **项目背景**：业务方提出一个模糊问题，例如“要不要加大内容营销投入”“新客增长放缓怎么办”。你需独立完成全链路分析并支持决策。
- **业务目标**：完成：业务问题定义→指标与口径→数据质量检查→提取清洗→方法选择→分析→可视化→结论与不确定性→方案比较→行动建议→效果验证计划。
- **最终产出**：完整项目包：问题定义书+数据字典+底表/查询+分析报告+决策备忘录+复盘计划
- **验收标准**：全链路 11 步齐全且每步有产出,通过 X3 误区清单审查,决策有比较与留痕,行动有验证指标与复盘日期
- **常见失败方式**：范围贪大无法收尾,口径不清导致结论被推翻,无验证计划沦为一次性报告,模拟数据未标注
- **作品集形式**：完整项目包即为个人作品集核心件；建议附一页“我的方法论”说明。
