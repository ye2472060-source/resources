# SEO + GEO Growth Academy — 交互式学习平台

一套系统、可实践的 SEO、GEO（生成式引擎优化）与网站增长自学知识体系，以单文件交互式 HTML 平台交付。

## 文件清单

| 文件 | 说明 |
|---|---|
| `index.html` | 交互式学习平台主文件，双击即可在浏览器打开，无需安装、无需联网 |
| `参考资料清单.md` | 全部 64 条参考资料的原始网址、类型、对应模块、更新时间与可支持的结论 |
| `知识体系总览.md` | 十大模块的逻辑关系、依赖结构与推荐学习顺序 |
| `README.md` | 本说明文件 |

## 研究范围

- **模块 A 互联网营销与搜索基础**：搜索引擎原理、SERP、搜索意图、流量类型、核心指标、用户旅程、网站技术基础、三类网站差异
- **模块 B SEO 核心知识体系**：关键词研究、竞品与 SERP 分析、网站架构、技术 SEO、页面 SEO、内容 SEO、外链、国际 SEO、数据诊断、政策合规
- **模块 C GEO 与 AI 搜索优化**：GEO 定义与边界、生成式搜索产品、引用机制、品牌可见度、可引用内容、AI 爬虫与访问控制、GEO×SEO 协同
- **模块 D 网站建设与运营**：目标与 KPI、架构与页面体系、体验与性能、转化路径、维护与上线、运营管理
- **模块 E 内容营销与内容生产**：需求研究、策略与排期、生产流程、AI 辅助生产、分发复用、效果评估
- **模块 F 其他平台的流量获取**：YouTube、LinkedIn、Instagram、Facebook、TikTok、Pinterest、Reddit、Quora、垂直社区、邮件营销、数字公关、联盟、付费流量、渠道策略
- **模块 G 数据分析与效果评估**：GA4、GSC、Bing Webmaster Tools、UTM、指标解读、线索与归因、A/B 测试
- **模块 H 转化率优化与业务增长**：转化路径、页面说服力、表单优化、指标体系、诊断与实验、B2B 与 DTC 差异
- **模块 I 研究、工具与工作流**：关键词/竞争工具、审计检测工具、分析平台配置、GEO 工具、工作流与模板
- **模块 J 综合项目与实战能力**：十个递进式实战项目（诊断→研究→规划→优化→内容→GEO 协同→渠道→数据→实验→复盘）

共 **184 个知识节点**，每个节点包含：核心定义、重要性、前置知识、操作步骤、相关工具、典型案例、常见错误、实践练习、验收标准、资料来源、知识关联、学习优先级、难度等级、证据等级与最后核验日期（2026-10-15）。

## 平台功能

1. **三种可视化视图**
   - 全局知识地图：首页展示十大模块的层级依赖关系图 + 模块卡片（含进度）
   - 树状知识结构：模块页按「章节→节点」二级树展示，支持展开/收起、筛选
   - 学习路径图：六个阶段的时间线，含知识点、任务、验收标准与进入条件
2. **知识详情面板**：点击任意节点，展示定义、原理、步骤、工具、案例、错误、练习、验收标准、可点击的来源链接、前置与相关知识跳转
3. **全局搜索**：顶部搜索框（快捷键 `/`），支持节点名称、定义、模块名匹配，回车打开第一个结果
4. **条件筛选**：按学习层级（L1/L2/L3）、难度（基础/进阶/高阶）、学习状态（未开始/学习中/已掌握）与关键词筛选
5. **学习进度**：标记「学习中 / 已掌握」，侧边栏与首页实时显示进度；可导出 JSON、可重置
6. **参考资料视图**：64 条资料可按模块、类型筛选与关键词搜索，全部链接可直接打开
7. **响应式与主题**：适配桌面、平板、手机；支持浅色/深色主题

## 使用建议

1. 先读「项目说明 → 证据分级规则」，建立对 GEO 领域证据的判断标准。
2. 按「学习路径」六个阶段推进；每个阶段先学知识点、再完成实践任务、对照验收标准自检。
3. 尽早选定一个真实网站（自有、实习或自建测试站），用模块 J 的十个项目贯穿练习，最终形成作品集。
4. GEO 相关节点都标注了证据等级（官方/研究/实践/待验证）。对任何"必然提升 AI 推荐"的说法保持警惕——本平台不提供此类保证。

## 学习状态与本地存储（重要限制）

- 学习进度保存在**当前浏览器的 localStorage**（键名 `seogeo_growth_progress_v1`）。
- 刷新页面不丢失；但**仅存在于这台设备的这个浏览器**——更换浏览器、清除站点数据、使用隐私模式都会丢失。
- 这不等于云端同步或备份。请定期用进度面板的「导出进度 JSON」备份。

## 更新机制

- 静态 HTML **不会**自动更新内容。知识更新需要重新研究并修改文件。
- 建议每 3 个月按 `参考资料清单.md` 复核一次官方文档（GEO、AI 搜索、平台政策变化快）。
- 内容数据（`MODULES` / `STAGES` / `SOURCES` 三个 JavaScript 常量）与样式和交互代码分离：修改数据即可新增模块、修订知识点或更新来源，无需改动页面代码。

## 技术说明

- 单文件实现：原生 HTML + CSS + JavaScript，无外部 CDN、无框架、无外部字体依赖，可完全离线打开。
- 设计规范：页面背景 `#F5F7FA`、卡片 `#FFFFFF`、主文字 `#1F2937`、主强调 `#2563EB`，十个模块各有专属标识色；字体优先 Inter / PingFang SC / Microsoft YaHei。
- 如需修改内容：用文本编辑器打开 `index.html`，搜索 `const MODULES=` 定位知识数据。
